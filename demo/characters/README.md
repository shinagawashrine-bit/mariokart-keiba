# キャラクター表示デモ

スマホの投票画面のカートをキャラクター画像に差し替えた、独立した試作用ページ。

- URL: `https://shinagawashrine-bit.github.io/mariokart-keiba/demo/characters/#bet`
- 投票、取消、券種変更、枚数変更を試せる。
- 「最初から」または再読み込みでデモ用チップ1,000枚に戻る。自動締切はない。
- データはメモリー内だけに保存し、Firebaseにも本番のブラウザーストレージにも接続しない。
- 画像・スクリプトをHTML内に含め、外部スクリプトを読み込まない。CSPでネットワーク接続も禁止する。
- このフォルダーの追加だけでは、本番の `index.html` や `shim.js` は変わらない。

表示素材は、この会話で作成した試作用画像。採用後も本体とは分離したデモとして動作する。本体のキャラクター表示と同じく、画像を切り取らず枠内に収める。

ローカル確認（リポジトリルートから）:

```sh
python3 tests/character_demo.py
```
